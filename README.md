# board-agnostic-public

## Latar Belakang & Masalah
Abstraction layer GPIO/UART/SPI lintas Arduino, RPi, ESP32, Tessel

## Mengapa repo ini dibuat? (Teknologi Lama / Isu yang Belum Terselesaikan vs Repo Ini)
**Masalah saat ini:** Johnny-Five tidak support ESP32; setiap board punya API berbeda

**Solusi Repo Ini:**
Repo ini bertujuan untuk menyediakan solusi yang lebih ringan, modern, dan spesifik untuk ekosistem JavaScript/TypeScript yang menyelesaikan masalah di atas.
