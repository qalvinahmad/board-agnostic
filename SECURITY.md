# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub's private vulnerability reporting for this repository](https://github.com/qalvinahmad/board-agnostic/security/advisories/new). Do not disclose an unpatched vulnerability in a public issue or discussion.

Include the affected version or commit, the impact, and a minimal reproduction when possible. The maintainers will investigate and coordinate a fix and disclosure. This is a community project without a guaranteed response-time SLA.

If private vulnerability reporting is unavailable, contact the repository maintainer through their GitHub profile and request a private channel.

## Scope and support

Security fixes are evaluated for the latest repository state. The project is an early-stage prototype; it has no verified physical-board backend and makes no production-readiness claim. Review hardware-specific safety and access controls independently.
